# Panther 500-triangle model

Approved fuller-leg title model. Total: 500 triangles, including the unchanged 172-triangle head. Body: 282; tail: 32; rose: 14. Thighs retain their original topology and have fuller proportions. Each shin uses eight triangles with a substantial ankle and the original boot texture.

`panther-500.glb` is the approved asset. Comparison images and running GIF show the previous preview and this revision. The original source and previous candidate are retained for reproducibility. Verification checks all six animations, head geometry, materials, joint transforms, triangle validity and tail attachment.

The preview scripts use the existing local character Site tools and installed meshoptimizer paths. This commit stores the approved asset and review evidence; runtime integration is separate.

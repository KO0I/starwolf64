# Pigma facial edits

The exact head from the Before comparison is retained, with the original snout and nostrils restored. Dark goggle rims approach the original outer scale while following the sleepy yellow eye shape, with a narrow bridge. The small red mouth sits below the restored snout. Skull shape, cheeks, ears, original skin colors, headset, orange bodies, rigs, and animations are preserved.

The checker locks every source triangle outside the eyes and mouth, including the entire original snout and nostrils, including its original positions, normals, UVs and material. Comparison renders use the same camera framing before and after. Pigma has no active runtime crew slot.

Rebuild with `python3 -B tools/preview_pigma_eyes.py`. Verify with `python3 -B tools/preview_pigma_eyes.py --check` or `python3 -B tools/check_pigma_head.py`. Retain CREDITS.md and README_TheRegressor.txt when distributing models.

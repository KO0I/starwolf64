Starwolf WASM

Select a Star Fox 64 US v1.1 ROM in the browser builder.
Preparation happens on your device; the ROM is never uploaded.

For a downloaded prepared game, run: python3 start.py
This uses only Python 3 and opens the game on localhost.
You can choose a different port with: python3 start.py --port 8666
The player needs HTTP hosting; opening index.html as a file will not run it.

A prepared download contains assets extracted from your ROM. Keep it for your own use.
Source: https://github.com/KO0I/starwolf64/tree/starwolf/wasm-port-exploration
